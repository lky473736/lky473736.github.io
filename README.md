# lky473736.github.io

Gyuyeon Lim's personal site, built with Jekyll on the [Academic Pages](https://github.com/academicpages/academicpages.github.io) template.

- Site config: `_config.yml`
- Homepage content: `_pages/about.md`
- Nav links: `_data/navigation.yml`
- CV: `files/cv.pdf` (source: `cv.tex`)

## Running locally

```bash
bundle install
bundle exec jekyll serve -l -H localhost
```
